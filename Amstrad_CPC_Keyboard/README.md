# Amstrad CPC Troubleshooting Keyboard
Started off as a quick'n'dirty keyboard for my 2nd CPC664 motherboard that's missing the top case/keyboard, then morphed to a generic CPC keyboard that could be used for troubleshooting naked motherboards.<br>

The CPC6128/Plus keyboard is a simple rectangle so I based this keyboard on that design, but using CPC464 colouring (that I grew up with).  The initial CPC464/664 keyboard design was abandoned/not completed in favour of the CPC6128 design.<br>

![Proposed troubleshooting keyboard layout](/Amstrad_CPC_Keyboard/CPC6128/Keyboard-Layout-Editor/amstrad-cpc6128.png)

And now I've decided to just concentrate on a simple tactile switch version, nice and compact, suitable for troubleshooting purposes.<br>

As there are different connectors used on the CPC464, CPC664 and CPC6128/Plus computers I decided to use just one connector on the keyboard itself and handle the motherboard connection by using different cable sets (to be designed).<br>

## Proposed BOM (for Cherry version)
- 74 x Cherry MX-type key switches in total
- 63 x 1u
- 1 x ISO ENTER
- 1 x 1.5u (TAB)
- 1 x 1.75u (CAPS LOCK)
- 2 x 2.5u (COPY & CTRL)
- 1 x 3u (number pad ENTER)
- 1 x 7u (SPACE)
- 1 x SPST power switch
- 1 x LED & resistor
- 2 x 10-pin header (for keyboard)
- 1 x 2-pin header (for power)
